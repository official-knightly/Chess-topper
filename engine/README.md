# Engine assets

Place the matching Stockfish.js wrapper, WASM binary, and any worker file from the same distribution in this folder.

Expected paths:
- `engine/stockfish-19-lite.js`
- `engine/stockfish-19-lite.wasm`
- `engine/stockfish-19-lite.worker.js` (if required by that build)

These matching engine assets are currently missing, so analysis will not start until they are added. Do not mix files from different builds. Preserve upstream GPLv3 license and copyright notices.
